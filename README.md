# SAP MM - Procurement & Inventory System
SAP MM inspired end-to-end Material Management system built with PHP & MySQL.

🔗 Project Link: https://github.com/sanikakokatepatil-lang/SAP-MM-Project

### 🚀 Features
- Material Master Management (MM01/MM02)
- Vendor Management 
- Real-time Stock Overview
- Purchase Order & Goods Receipt (P2P)

### 🛠️ Tech Stack
PHP | MySQL | HTML | CSS | XAMPP | SAP MM Concepts

### ⚙️ How to Run
1. Copy to C:/xampp/htdocs/
2. Start Apache & MySQL in XAMPP
3. Open http://localhost/SAP-MM-Project/
